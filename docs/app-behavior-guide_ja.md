# MindGalaxy アプリ動作ガイド

このドキュメントは、MindGalaxy がユーザー視点でどのように動くか、画面遷移・機能・ゲーム的演出・データの流れを説明します。NotebookLM 等でプロダクト理解のための参照資料として使えます。

---

## 1. アプリのコンセプト

**MindGalaxy** は、頭に浮かんだ思考を「星」として宇宙空間に配置し、時間をかけて振り返ることを支援するアプリです。

### 核となるメタファー

| 概念 | アプリ内の表現 |
|------|----------------|
| 思考 | 星（テキスト） |
| 気づき | 星のグロー（光） |
| 行動 | 星から放たれる粒子 |
| 分類（未来/過去/感情/行動） | 星の色・ドラッグ方向 |
| 振り返り | 中央星タップ → 星座形成 → 再訪ダイアログ |
| 記録の蓄積 | 銀河（ホーム画面の星々） |
| 週次振り返り | 週間銀河画面 |

データは端末内（Hive）に保存されます。ログインは任意で、現時点ではクラウド同期は行われません。

---

## 2. 初回起動〜チュートリアル

初回起動時、`settings` Box の `tutorialDone` が false のため、インタラクティブチュートリアルが始まります。

### チュートリアルステップ（0〜7）

| Step | ユーザー体験 |
|------|-------------|
| 0 | 「思ったことは、星になる」— タップで次へ |
| 1 | 中央にテキスト入力。「今、何が頭に浮かんでる？」Enter で確定 |
| 2 | 「それ、星になった」— 1 秒表示 |
| 3 | 白い星が出現。ドラッグして分類（上=未来、下=過去、左=感情、右=行動）。画面上部にコンパス表示 |
| 4 | 「気づきと行動で、星は成長する」 |
| 5 | 「これが、あなたの宇宙」— 星が Hive に保存されホーム銀河の一部に |
| 6 | 「次からは右下の + を押してね」— FAB にスポットライト |
| 7 | 週間銀河のプレビュー。「1 週間後の宇宙」— タップでチュートリアル完了 |

完了後 `tutorialDone = true`。以降は通常のホーム画面。

---

## 3. ホーム画面（メイン銀河）

ホームは黒背景の宇宙。ランダムな小さな背景星、ユーザーの思考星、中央の大きな星が表示されます。

### 3.1 画面レイアウト

```
┌─────────────────────────────────────┐
│ [≡]                    (ブラックホール) │  ← 左上: ドロワー / 右上: 削除ゾーン
│                                     │
│         ☆  ☆    ☆                   │  ← 思考星（ドラッグ可能）
│              ★                      │  ← 中央星（再訪トリガー）
│    ☆              ☆                 │
│                                     │
│ [観測]              [流星群]  [+]    │  ← 下部コントロール
└─────────────────────────────────────┘
```

### 3.2 思考星の操作

| 操作 | 結果 |
|------|------|
| **ドラッグ** | 星を移動。離した位置が保存される |
| **ドラッグ方向** | カテゴリ変更（上=未来/青、下=過去/紫、左=感情/ピンク、右=行動/黄） |
| **タップ** | 思考の詳細ポップアップ（閲覧・編集への導線） |
| **長押し** | 詳細ダイアログ |
| **右上ブラックホールへドラッグ** | 削除（吸い込みアニメーション後、Hive から消去） |

星の見た目は成長段階で変化します:

- **段階 0**: 思考のみ — 白っぽい星
- **段階 1**: 気づきあり — グロー強化
- **段階 2**: 行動あり — 粒子が周囲に放出、さらに光る

新しく追加した星は約 5 秒間ハイライトされます。

### 3.3 表示件数

ホームには最新 **30 件**まで表示（古い星は Hive に残るがホームからは非表示）。観測モードでは全件アクセス可能。

### 3.4 中央星（再訪の入口）

中央の大きな星をタップすると **再訪イベント** が始まります。

**前提条件:**

- 本日の再訪クォータが残っている（1〜3 回/日、日付で変動）
- 再訪候補の星が存在する

**中央星の赤バッジ**は「候補の数」ではなく「今日あと何回再訪できるか」を示します。

## 4. 思考の入力（+ ボタン）

右下 FAB をタップすると全画面の **入力画面** が開きます。

### シンプル入力

- 「思考」フィールド 1 つ（最大 200 文字）
- 入力に応じてプレビュー星が大きくなる
- 「⭐ 星を銀河に放つ」で保存 → ホームに新しい星が出現

### まとめて入力

モード切替で 3 フィールド:

1. **思考** — 星のサイズ
2. **気づき** — グロー（光の輪）
3. **行動** — 粒子の数と広がり

保存時は **星座共鳴アニメーション**（波紋が広がり銀河へ還元する演出）の後、ホームに戻ります。

### 編集フロー

既存の星から編集に入った場合、同画面で更新。未保存で戻ろうとすると破棄確認ダイアログ。

### 広告

プレミアムでなければ入力画面下部にバナー広告（iOS/Android のみ。Web では非表示）。

---

## 5. 再訪（振り返り）フロー

再訪はアプリの核心機能です。時間が経った思考を改めて見つめ直すことを促します。

### 5.1 候補の選び方

1. **タイミングベース**: 作成から約 1 日 / 3 日 / 7 日後（±18 時間）の星
2. **スコアリング**: 行動・気づきが未記入の星を優先。長文・古い星も加点
3. **フォールバック**: 全星に行動が書かれている場合、最古の星から最大 4 個
4. 2〜4 個の星が選ばれ、**1 つが主星**、残りが文脈星

### 5.2 星座形成の演出

中央星タップ後:

1. 選ばれた星が中央周辺の幾何学スロットへ **弾むように移動**（1 星ずつ 90ms ずつ遅延）
2. 中央から各星へ **光の線**が順次接続（ConstellationLinesOverlay）
3. 線の演出完了後、**再訪ダイアログ**が自動表示

### 5.3 再訪ダイアログ

- 星座には自動生成名（例: 「Prospect座」「Nebula座」）— カテゴリ構成から決定
- 主星の思考内容を表示
- 文脈星があればカード一覧
- **状況に応じたプロンプト**:
  - 行動未記入 → 「この一歩を、今踏み出しませんか？」
  - 気づき未記入 → 「新しい気づき、書き足してみませんか？」
  - 7 日以上経過 → 「時間を置いて見えてきた変化を…」
  - それ以外 → 「今の視点で、もう一度この思考を眺めてみませんか？」

**選択肢:**

- **あとで** — 星座を解散、星は元の位置に戻る。クォータは消費しない
- **内容を更新する** — まとめ入力画面へ。周囲の文脈星は読み取り専用カルーセルで表示

### 5.4 再訪後のスケジュール

再訪で保存すると `revisitCount` が進行:

| revisitCount | 次の再訪タイミング |
|--------------|-------------------|
| 1 → 2 | 作成から 1 分後（デバッグ・短期確認用） |
| 2 → 3 | 作成から 7 日後 |
| 3 → 終了 | revisitAt = null（自動再訪終了） |

1 日の再訪イベント完了数は `reflectionDailyCount` で記録（保存した場合のみカウント）。

## 6. 観測モード

左下の「観測モード」ボタンで切り替え。

### 通常銀河との違い

| 項目 | 通常モード | 観測モード |
|------|-----------|-----------|
| 星の操作 | ドラッグ・タップ可能 | 閲覧のみ |
| 表示 | 2D 自由配置（最新 30） | 縦タイムライン（全件） |
| スクロール | なし | 上下スワイプで時間軸移動 |
| フォーカス | — | 画面中央に近い星がハイライト＋テキスト表示 |
| 検索 | — | キーワード検索、前後ジャンプ |

観測モード開始時は **最新の星**（タイムライン末尾）が中央に来るようスクロール位置を初期化。

星は作成日時の古い順に縦一列（140px 間隔）に並び、波形オフセットで銀河のような配置に見せます。

## 7. 週間銀河

ドロワーまたはチュートリアルからアクセス。1 週間分の思考を可視化して振り返ります。

### 画面構成

- **上部 65%**: 銀河チャート（CustomPaint）
  - 月〜日の 7 列
  - カテゴリ別レイヤー（未来→感情→行動→過去→未分類）
  - 星は作成日時に沿ってプロット
- **下部**: 統計カード
  - 今週の思考数
  - カテゴリ別内訳
  - 気づき・行動の記入数
  - 密度オーブ（週 28 件を 100% とした達成感メーター）

### 週の切り替え

AppBar に週ナビゲーター。タップで年・月・週のピッカー（iOS 風ドラムロール）。

### シネマティックモード

今週 30 件以上かつ 3 カテゴリ以上が各 5 件以上のとき、より密度の高い「映画的」星野描画に切り替わります。

### シェア

共有ボタンで画面を PNG キャプチャ:

- **モバイル**: OS 共有シート
- **Web**: ブラウザダウンロード

## 8. 流星群（リワード演出）

左下の流星群ボタンからアクセス。

### 流れ

1. 「開発者を支援」ダイアログ — 広告視聴で 12 時間流星群を表示
2. **リワード広告**視聴完了（または Web/広告無効時は即時）
3. `meteorExpiryTime` を現在 + 12 時間に設定
4. ホーム背景に **流星アニメーション**（1〜3 本がランダムに流れる）

流星は装飾的な演出であり、ゲームプレイやデータには影響しません。

## 9. 設定画面

ドロワー → 設定

### データ管理

| 機能 | 動作 |
|------|------|
| **エクスポート** | 全 Thought を JSON 化し共有シートでファイル送信 |
| **インポート** | JSON を選択 → 確認ダイアログ → **全件置換**（既存データは消える） |

### アカウント

- **Google / Apple ログイン**（Firebase Auth）
- ログインなし（ゲスト）でも全機能利用可能
- ログイン状態は端末内に表示名のみ保存。クラウド同期は将来機能

### プレミアム

UI はあるが「Coming Soon」。`isPremium` が true の場合は広告非表示。

## 11. カテゴリ（星の色）

| 方向 / キー | 色 | 意味 |
|-------------|-----|------|
| future（上） | 青 | 未来への展望 |
| past（下） | 紫 | 過去の記憶 |
| emotion（左） | ピンク | 感情・気持ち |
| action（右） | 黄 | 行動・意志 |
| neutral | 白 | 未分類 |

チュートリアル・ホームのドラッグ分類と、入力画面の文脈カード色で一貫しています。

## 12. データのライフサイクル

```
[入力] → Thought 作成 → Hive 保存
           ↓
[ホーム] 星として表示（dx/dy, category, 見た目パラメータ）
           ↓
[操作] ドラッグで移動・分類 / 編集 / ブラックホールで削除
           ↓
[時間経過] revisitAt / isReadyToRevisit で再訪候補に
           ↓
[再訪] 星座形成 → ダイアログ → 編集 → スケジュール更新
           ↓
[観測モード] 全履歴を時系列で閲覧
           ↓
[週間銀河] 週単位で集計・可視化
           ↓
[バックアップ] JSON エクスポート / 別端末へインポート
```

`isArchived` と `clusterId` は将来の「過去ログ銀河」機能用にフィールドが用意されていますが、現行 UI では主に未使用です。

## 13. 広告の表示ルール

| 場所 | 種類 | 条件 |
|------|------|------|
| 入力画面下部 | バナー | モバイル、非プレミアム、広告有効 |
| 流星群 | リワード | 同上 |

## 14. 言語対応

端末のロケールに応じて日本語/英語を自動切替。カテゴリの DB 値は言語非依存（`future` 等）で、表示ラベルのみ翻訳されます。

---

## 15. 典型的なユーザージャーニー

### 毎日の利用

1. 思いついたことを + で記録（シンプル or まとめて）
2. 余裕があれば星をドラッグして分類
3. 中央星に赤バッジが出たらタップして再訪
4. 週末に週間銀河で一週間を俯瞰

### データ移行

1. 旧端末: 設定 → エクスポート → JSON を保存
2. 新端末: アプリインストール → 設定 → インポート → JSON 選択

### ログイン（任意）

将来の同期に備えて Google/Apple でサインイン。現時点では表示名の記録のみ。

---

## 16. エッジケース・制限

- ホーム表示は最大 30 星（それ以上は観測モードで確認）
- 再訪は 1 日 1〜3 回まで（日付で上限が変わる）
- インポートは全置換 — 部分マージなし
- Firebase 未設定環境ではログインは「設定後に利用可能」メッセージ
- オフライン完結（広告・Firebase 除く）

---

## 17. 世界観と UX デザイン原則

1. **宇宙メタファーの一貫性** — 記録=星を放つ、削除=ブラックホール、振り返り=星座
2. **触覚フィードバック** — 再訪・保存・分類開始時に HapticFeedback
3. **成長の可視化** — テキスト量がそのまま星のサイズ・光・粒子になる
4. **押し付けない再訪** — 「あとで」で逃げられる。クォータも緩い（1〜3/日）
5. **ダーク UI** — 夜空に映える配色（`AppColors` の深宇宙トーン）
